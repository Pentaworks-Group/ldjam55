# About
In Summoning Lunatic, Infectious Mold Entity (S.L.I.M.E) you play as exactly that: An Infectious Mold Entity.

Try to gather as much territory as possible or reach target field. Combat with other Molds for the precious moist forrest ground.

To control in which direction you grow you can set or remove walls.

# How to Play

### There appears to be a bug, where it fails to load the level. You end up with an empty grassfield, reloading the page does help.

Place Molds with the spawn button, place or remove Walls with the associated buttons in the game.
